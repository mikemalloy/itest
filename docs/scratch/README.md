# Scratch

A local-only space for personal notes, drafts, and throwaway documents.

**Everything in this directory except this README is gitignored** — nothing you
put here is committed or uploaded to GitHub. Write freely: design sketches,
meeting notes, TODO lists, half-formed ideas, command snippets.

The directory itself is tracked (via this one file) so it always exists in a
fresh clone; the `.gitignore` rules that keep its contents local live in the
repo-root [`.gitignore`](../../.gitignore).

If a note matures into something worth sharing, move it out into `docs/` proper
and commit it there.
